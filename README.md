# MentorBay

> **Connect · Grow · Succeed**

A digital platform connecting mentors and mentees across Kenya and Africa through mentorship programs, events, and progress tracking.

## Status
Design phase - building high-fidelity, viewable HTML pages before migrating to the production stack.

## Pages
- `index.html` - Home / landing page
- `mentors.html` - Browse Mentors (with working filters, search, and sort)

_More pages coming: Mentor Profile, Programs, Program Detail, Events, Event Detail, Success Stories, Resources, authentication, and dashboards for Mentee / Mentor / Admin._

## User roles
- **Mentee** - search mentors, join programs, attend events, set goals, track progress
- **Mentor** - publish programs, schedule sessions, host events, track mentees
- **Admin** - approve mentors, verify users, moderate content, generate reports

## Tech
- **Design phase:** HTML + Tailwind CSS (CDN)
- **Production (planned):** Next.js · TypeScript · Tailwind CSS · Supabase

## How to view
Open any `.html` file directly in your browser. Images load from hosted URLs, so an internet connection is required.
